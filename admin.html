Connexion à GitHub

Pour publier les changements, il faut un jeton d'accès GitHub (Personal Access Token) avec le droit d'écrire sur le dépôt Rafael-ma0508/Solid-R_Nanterre.

Sur GitHub : Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token → sélectionner ce dépôt → autorisation "Contents: Read and write".

Ce jeton reste uniquement sur cet appareil (stocké dans le navigateur), il n'est jamais envoyé ailleurs qu'à GitHub.
